# Checklist SEO post-lancio

- [ ] backup completo del sito precedente;
- [ ] export di URL, title, description, canonical e backlink;
- [ ] verifica proprietà e accessi Search Console;
- [ ] invio della nuova sitemap;
- [ ] controllo copertura, indicizzazione e URL canoniche;
- [ ] controllo Core Web Vitals e Lighthouse su mobile;
- [ ] scansione redirect, catene, loop e 404;
- [ ] monitoraggio traffico organico, query branded/locali e conversioni;
- [ ] controllo dei backlink verso URL modificate;
- [ ] verifica tecnica e log server dopo 24 ore;
- [ ] confronto ranking, copertura e conversioni dopo 7 giorni;
- [ ] audit completo dopo 30 giorni.

Non richiedere rimozioni da Google quando è disponibile un redirect corretto.
